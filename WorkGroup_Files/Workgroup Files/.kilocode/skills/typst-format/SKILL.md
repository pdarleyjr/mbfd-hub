# Typst Format Skill

## Purpose
Apply professional typesetting with 2-column layouts, proper gutters, and title breakouts using Typst.

## Key Functions
- `#columns(2, gutter: 8pt)` for 2-column body layout
- `#place(top + center, scope: "parent", float: true)` for title breakout from columns
- High-fidelity image placement with relative paths

## Standards
- 2-column layout with 8pt gutters
- Title elements break out of column constraints
- Machine-readable metadata in document header
- Professional "Modern Professional" styling
