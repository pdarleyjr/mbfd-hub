## What Is MBFD Hub?

MBFD Hub is the Miami Beach Fire Department's internal operations platform — a containerized Laravel application running on a dedicated VPS at `145.223.73.170`.

It currently provides:
- Daily operational forms
- Vehicle inspections and defect reporting
- Station inventory workflows
- Capital project tracking
- Workgroup / evaluation management
- Training resources
- Personnel, apparatus, and equipment administration
- Google Sheets apparatus synchronization
- Equipment intake and Snipe-IT integration

### 25. DeerFlow Gateway Upload Router UID Mismatch Fix (2026-03-19)
- **Root cause**: Gateway writes uploaded files as `root:root 644` via `file_path.write_bytes(content)`. The sandbox's `gem` user (UID 1000) cannot overwrite these files when the Gateway calls the sandbox's `/v1/file/write` API, causing `[Errno 13] Permission denied`.
- **Fix applied**: Patched `backend/app/gateway/routers/uploads.py` — added `import os` and `os.chmod(file_path, 0o666)` after every `write_bytes()` call (both uploaded files and markdown conversions).
- **Verified**: Test upload confirmed file permissions changed from `-rw-r--r--` (644) to `-rw-rw-rw-` (666).
- **Gateway restarted**: `docker restart deer-flow-gateway` applied the code changes.
- **This is an MBFD patch** — do NOT revert when pulling upstream DeerFlow updates.
- **Error documented**: ERROR-078 added to `AI_AGENT_ERRORS.md`.
