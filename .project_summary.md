## What Is MBFD Hub?

MBFD Hub is the Miami Beach Fire Department's internal operations platform — a containerized Laravel application running on a dedicated VPS at `145.223.73.170`.

It currently provides:
- Daily operational forms
- Vehicle inspections and defect reporting
- Station inventory workflows
- Capital project tracking
- Workgroup / evaluation management
- Training resources
- Personnel, apparatus, and equipment administration
- Google Sheets apparatus synchronization
- Equipment intake and Snipe-IT integration

### 17. DeerFlow 2.0 Emergency Recovery (2026-03-17)
- **Root cause #1 (DB lockout)**: Previous agent ran `chown -R 1000:1000` on `.deer-flow/` → SQLite WAL files became non-writable → API threw 500 on every request. Fixed by `docker exec deer-flow-langgraph chmod -R 777 /app/backend/.deer-flow/`.
- **Root cause #2 (MCP hallucination)**: `filesystem` MCP server injected into `extensions_config.json` with host-only paths. Removed — only 5 authorized servers remain.
- **Root cause #3 (nginx stale DNS)**: After `docker compose restart`, Docker reassigned container IPs but nginx cached old IPs. Fixed by `docker exec deer-flow-nginx nginx -s reload`.
- **Root cause #4 (AIO sandbox upload permission)**: New sandbox containers created by the provider have `/mnt/user-data` as `root:755`. Fixed permanently by adding `chmod -R 777 /mnt/user-data` to `_create_sandbox()` in `aio_sandbox_provider.py`.
- **Root cause #5 (upstream restructure)**: Upstream DeerFlow 2.0 `0091d9f` renamed `backend/src/` → `backend/app/` + `backend/packages/harness/deerflow/`.
